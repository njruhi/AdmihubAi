# AdmihubAi 🎓

> **বিশ্ববিদ্যালয় ভর্তি পরীক্ষা — মানবিক বিভাগ (Arts Unit)** এর জন্য প্রিমিয়াম পার্সোনাল **AI স্টাডি এজেন্ট + লার্নিং প্ল্যাটফর্ম**।
> সম্পূর্ণ ব্রাউজার-ভিত্তিক, কোনো সার্ভার নেই, তোমার API key তোমার ডিভাইসেই থাকে।

iOS / ChatGPT-অনুপ্রাণিত ডিজাইন · গ্লাসমরফিজম · ডার্ক ও লাইট মোড · সুপার-ফাস্ট স্ট্রিমিং উত্তর।

## 🚀 শুরু করা

```bash
npm install
npm run dev        # http://localhost:5173
```

প্রথমবার খুললে **⚙️ সেটিংস** → অন্তত একটি API key বসাও (সবচেয়ে দ্রুত: **Groq**, ফ্রি টিয়ার আছে)।
Key ছাড়াও টাইমার, ফ্ল্যাশকার্ড, নোট, কুইজ ব্যাংক ও প্রোগ্রেস ট্র্যাকার **পুরোপুরি কাজ করে**।

| কমান্ড | কাজ |
|--------|-----|
| `npm run dev` | ডেভ সার্ভার (HMR) |
| `npm run build` | প্রোডাকশন বিল্ড → `dist/` |
| `npm run preview` | বিল্ড প্রিভিউ |
| `npm run typecheck` | TypeScript চেক |
| `npm test` | লজিক + রেন্ডার টেস্ট |

### 🔑 API key কোথায় পাবে

| প্রোভাইডার | লিংক | নোট |
|-----------|------|-----|
| Groq | console.groq.com/keys | সবচেয়ে দ্রুত, ফ্রি টিয়ার — **রেকমেন্ডেড** |
| Google Gemini | aistudio.google.com/app/apikey | ফ্রি টিয়ার, লম্বা কনটেক্সট |
| OpenRouter | openrouter.ai/keys | অনেক মডেল এক key-তে |
| Mistral | console.mistral.ai | ইউরোপীয় বিকল্প |
| Tavily | app.tavily.com | শুধু ওয়েব সার্চের জন্য |

## 🧱 আর্কিটেকচার

```
index.html ──► src/main.tsx ──► src/App.tsx
                                  │
   ┌──────────────────────────────┼─────────────────────────────┐
   │ Sidebar / TopBar             │  lazy-loaded views          │
   │                              ▼                             │
   │  chat · mcq · brain · knowledge · quizbank ·               │
   │  flashcards · notes · timer · progress                     │
   └────────────────────────────────────────────────────────────┘
                                  │
          store/store.ts (useSyncExternalStore + debounced persist)
                                  │
   lib/providers.ts  ·  lib/brain.ts  ·  lib/tavily.ts
   lib/fileParse.ts  ·  lib/exporter.ts  ·  lib/mcq.ts  ·  lib/storage.ts
```

**স্ট্যাক:** Vite 6 · React 18 · TypeScript (strict) · Tailwind CSS v4 · lucide-react · react-markdown · pdfjs-dist · mammoth

### কীভাবে কাজ করে

- **স্ট্রিমিং** — চারটি প্রোভাইডারই SSE; Groq/OpenRouter/Mistral OpenAI-কম্প্যাটিবল, Gemini `streamGenerateContent`। চাঙ্ক-বাউন্ডারি সেফ পার্সার, `AbortController` দিয়ে stop।
- **RAG (এমবেডিং ছাড়া)** — `chunkText` (৯০০ অক্ষর, ১৪০ ওভারল্যাপ) + **BM25-lite** (k1 1.4, b 0.72)। বাংলার জন্য কাস্টম টোকেনাইজার: `\p{M}` (কার/মাত্রা) ধরে রাখে, হালকা suffix + derivational stemmer (`বাংলাদেশের → বাংলাদেশ`, `প্রতিষ্ঠিত ↔ প্রতিষ্ঠা`), exact ম্যাচ পূর্ণ ওজন ও stem ম্যাচ ড্যাম্পড। আপলোড করা ডকে ১.১২× বুস্ট; কনটেক্সট ব্লক ৭০০০ অক্ষরে ক্যাপড, `[সূত্র n · নাম]` সাইটেশনসহ।
- **স্টোরেজ** — সেটিংস/চ্যাট/নোট/কার্ড/স্কোর `localStorage` (`admihub.` প্রিফিক্স, ২৫০ms ডিবাউন্স); Brain ডকুমেন্ট IndexedDB (`admihub-brain`)।
- **PDF এক্সপোর্ট** — স্টাইলড প্রিন্ট-উইন্ডো (কোনো ভারী লাইব্রেরি নয়), বাংলা ফন্ট-সেফ।
- **পারফরম্যান্স** — রুট-লেভেল code splitting; ইনিশিয়াল পেলোড **≈১৬৬ kB gzip**, প্রতিটি ভিউ চাঙ্ক ৩.৬–১২.৭ kB; `pdf.js` (৩৩৪ kB) ও `mammoth` (৩০৫ kB) শুধু ফাইল আপলোডের সময় লোড হয়; অ্যানিমেশন CSS-only।

## 🧪 টেস্ট

```bash
npm test
```

- `scripts/logic.mjs` — ৩৩টি অ্যাসারশন: MCQ JSON পার্সিং (এলোমেলো মডেল আউটপুট, বাংলা ক/খ/গ/ঘ উত্তর), BM25 রিট্রিভাল (১০টি বাস্তব ভর্তি-প্রশ্ন), markdown→HTML এক্সপোর্ট, মক-করা SSE স্ট্রিমিং (Groq + Gemini + এরর ম্যাপিং), Tavily পার্সিং, কুইজ ব্যাংক ও নলেজ বেসের ইন্টেগ্রিটি।
